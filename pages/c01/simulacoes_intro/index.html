    1.8. Simulações numéricas de modelos de crescimento natural

    Hora de implementarmos os métodos de Euler descritos na seção anterior.

    Vamos ver variações do modelo de crescimento natural. Primeiramente, vamos considerar o modelo clássico, de uma equação diferencial ordinária dx/dt=μx,\mathrm{d}x/\mathrm{d}t = \mu x,dx/dt=μx, com um parâmetro μ\muμ constante, representando a taxa de crescimento específico. Depois, vamos permitir que μ\muμ seja uma variável aleatória, representando uma incerteza no parâmetro. Em seguida, vamos considerar o caso em que μ={μt}t≥0\mu = \{\mu_t\}_{t\geq 0}μ={μt​}t≥0​ é um processo aleatório, representando uma variabilidade temporal aleatória no parâmetro. Por último, vamos considerar μ\muμ novamente constante mas com a equação perturbada por um termo estocástico, dx=μxdt+σdWt.\mathrm{d}x = \mu x \mathrm{d}t + \sigma \mathrm{d}W_t.dx=μxdt+σdWt​.

    Usaremos apenas dois pacotes do Julia. Um é o Plots.jl, para visualização das soluções. O outro é o Random, da biblioteca padrão, apenas para fixar a reprodução das notas (gerar sempre os mesmos conjuntos de números aleatórios, por motivos didáticos e de controle de versão).

    using Plots
theme(:ggplot2)
using Random
rng = Xoshiro(123)

    Modelo de equação diferencial ordinária

    Consideramos o problema de crescimento populacional

    {dxdt=μx,t>0,x(0)=x0. \begin{cases} \displaystyle \frac{\mathrm{d}x}{\mathrm{d}t} = \mu x, \quad t > 0,\\ x(0) = x_0. \end{cases} ⎩⎨⎧​dtdx​=μx,t>0,x(0)=x0​.​

    Para cada μ>0\mu > 0μ>0 fixo, temos a solução x(t)=x0eμt,x(t) = x_0 e^{\mu t},x(t)=x0​eμt, para t≥0.t \geq 0.t≥0.

    Resolvendo o problema de valor inicial pelo método de Euler, em um intervalo t0≤t≤T,t_0 \leq t \leq T,t0​≤t≤T, com t0=0,t_0 = 0,t0​=0, T>0T > 0T>0 e um passo de tempo Δt>0,\Delta t > 0,Δt>0, obtemos a sequência de valores aproximados

    xn+1=xn+μΔtxn,n=0,1,…,N, x_{n+1} = x_n + \mu \Delta t x_n, \quad n = 0, 1, \dots, N, xn+1​=xn​+μΔtxn​,n=0,1,…,N,

    onde NNN é um inteiro mais próximo de T/Δt.T/\Delta t.T/Δt.

    Escolhemos valores para T,T,T, μ\muμ e x0,x_0,x0​, além de t0=0t_0=0t0​=0:

    t0 = 0.0
T = 20.0
μ = 0.1
x₀ = 0.2
nothing

    Escolhemos, também, um valor para o passo de tempo, obtendo a malha temporal:

    Δt = 0.2
t = t0:Δt:T

    Isso nos dá N+1N+1N+1 pontos na malha, onde

    N = Int(round(T/Δt))

    Podemos pré-alocar um vetor para a solução numérica:

    x = Vector{Float64}(undef, N+1)
nothing

    Iniciando o vetor com o valor de x0x_0x0​ e iterando de acordo com o método de Euler, obtemos a solução numérica aproximada:

    x[1] = x₀
for n in 2:N+1
    x[n] = (1.0 + μ * Δt)x[n-1]
end

    De posse da solução podemos visualizar o crescimento exponencial e compará-lo com a solução exata

    plot(t, x, title="Crescimento exponencial \$(x_0 = $x₀, \\mu = $μ, T = $T, \\Delta t = $Δt)\$", titlefont = 10, xlabel = "t", ylabel="x", label="aproximação")

plot!(t, t -> x₀ * exp(μ * t), label="sol. exata")

    Refinando a malha, obtemos uma solução mais próxima, onde quase não vemos diferença:

    Δt = 0.02
t = t0:Δt:T
N = Int(round(T/Δt))
x = Vector{Float64}(undef, N+1)

x[1] = x₀
for n in 2:N+1
    x[n] = (1.0 + μ * Δt)x[n-1]
end

plot(t, x, title="Crescimento exponencial \$(x_0 = $x₀, \\mu = $μ, T = $T, \\Delta t = $Δt)\$", titlefont = 10, xlabel = "t", ylabel="x", label="aproximação", color=1)

    Modelo com parâmetros aleatórios

    Agora, vamos assumir uma incerteza em relação ao parâmetro, dada por uma distribuição normal, com média μˉ\bar\muμˉ​ e desvio padrão σ\sigmaσ: μ=N(μˉ,σ2).\mu = \mathcal{N}(\bar\mu, \sigma^2).μ=N(μˉ​,σ2).

    Façamos uma amostragem de um certo número MMM de valores.

    M = 100
μ̄ = 0.1
σ = 0.02
μ = μ̄ .+ σ * randn(rng, M)

histogram(μ, bins = 20, xlims=(0.0, 0.2), title="Histogram das realizações de \$\\mu \\sim \\mathcal{N}(\\bar\\mu, \\sigma^2); \\bar\\mu = $μ̄, \\sigma=$σ \$", xlabel="\$\\mu\$", titlefont=10, label=false)

    Agora, vamos resolver a equação para cada valor sorteado.

    Δt = 0.2
t = t0:Δt:T
N = Int(round(T/Δt))
x = Array{Float64}(undef, N+1, M)

x[1, :] .= x₀
for n in 2:N+1
    x[n, :] .= (1.0 .+ μ * Δt) .* x[n-1, :]
end

plot(t, x, alpha = 0.2, title="Conjunto de soluções \$(x_0 = $x₀, \\mu \\sim \\mathcal{N}($μ̄, {$σ}^2), T = $T, \\Delta t = $Δt)\$", titlefont = 10, xlabel = "t", ylabel="x", label=permutedims(["soluções"; fill(nothing, M-1)]), color=1)
plot!(t, x[:, 1], label="uma realização", linewidth=2, color=2)
plot!(t, sum(x, dims=2)/size(x, 2), linewidth=3, color=:orange, label="média")

    Modelo de equação diferencial aleatória

    Consideramos, agora, a equação aleatória

    dXtdt=μtXt, \frac{\mathrm{d}X_t}{\mathrm{d}t} = \mu_t X_t, dtdXt​​=μt​Xt​,

    onde {μt}t\{\mu_t\}_t{μt​}t​ é um processo aleatório dado por μt=μˉ+σsin⁡(Wt),\mu_t = \bar\mu + \sigma \sin(W_t),μt​=μˉ​+σsin(Wt​), onde μˉ,σ>0\bar\mu, \sigma > 0μˉ​,σ>0 e {Wt}t≥0\{W_t\}_{t\geq 0}{Wt​}t≥0​ é tal que W0=0,W_0 = 0,W0​=0, e Wt+τ−Wt∼N(0,τ)W_{t + \tau} - W_t \sim \mathcal{N}(0, \tau)Wt+τ​−Wt​∼N(0,τ) independentes.

    μ̄ = 0.1
σ = 0.05

for m in 1:M
    x[1, m] = x₀
    wt = 0.0
    for n in 2:N+1
        wt += randn(rng) * √Δt
        μt = μ̄ + σ * sin(wt)
        x[n, m] = (1.0 + μt * Δt) .* x[n-1, m]
    end
end

plot(t, x, alpha = 0.2, title="Soluções RODE \$(x_0 = $x₀, \\mu_t = $μ̄ + $σ\\sin(W_t), T = $T, \\Delta t = $Δt)\$", titlefont = 10, xlabel = "t", ylabel="x", label=permutedims(["soluções"; fill(nothing, M-1)]), color=1)
plot!(t, x[:, 1], label="uma realização", linewidth=2, color=2)
plot!(t, sum(x, dims=2)/size(x, 2), linewidth=3, color=:orange, label="média")

    Modelo de equação diferencial estocástica

    Finalmente, vamos considerar a equação estocástica

    dXt=μˉXtdt+σXtdWt, \mathrm{d}X_t = \bar\mu X_t \mathrm{d}t + \sigma X_t \mathrm{d}W_t, dXt​=μˉ​Xt​dt+σXt​dWt​,

    onde {Wt}t\{W_t\}_t{Wt​}t​ é um processo aleatório. Mais especificamente, vamos assumir que {Wt}t\{W_t\}_t{Wt​}t​ modela um movimento Browniano, tendo incrementos independentes e estacionários, dados por ΔWt=Wt+Δt−Wt∼N(0,Δt).\Delta W_t = W_{t + \Delta t} - W_t \sim \mathcal{N}(0, \Delta t).ΔWt​=Wt+Δt​−Wt​∼N(0,Δt).

    μ̄ = 0.1
σ = 0.05

for m in 1:M
    x[1, m] = x₀
    for n in 2:N+1
        dw = randn(rng) * √Δt
        x[n, m] = (1.0 + μ̄ * Δt) * x[n-1, m] + σ * x[n-1, m] * dw
    end
end

plot(t, x, alpha = 0.2, title="Soluções SDE \$(x_0 = $x₀, \\bar\\mu = $μ̄, \\sigma = $σ, dW_t \\sim \\mathcal{N}(0, \\Delta t), T = $T, Δt = $Δt)\$", titlefont = 9, xlabel = "t", ylabel="x", label=permutedims(["soluções"; fill(nothing, M-1)]), color=1)
plot!(t, x[:, 1], label="uma realização", linewidth=2, color=2)
plot!(t, sum(x, dims=2)/size(x, 2), linewidth=3, color=:orange, label="média")
