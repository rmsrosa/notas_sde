    10.8. O método de Milstein

    Vimos que o método de Euler-Maruyama para equações estocásticas multiplicativas é de ordem forte 1/2,1/2,1/2, ao contrário do método de Euler clássico, que é de ordem 1.1.1. É natural buscarmos de métodos de ordem mais alta também para equações estocásticas. Vamos ver, aqui, o método de Milstein, que é de ordem forte 1.1.1.

    Para simplificar, vamos considerar equações diferenciais estocásticas autônomas, da forma

    dXt=f(Xt) dt+g(Xt) dWt. \mathrm{d}X_t = f(X_t)\;\mathrm{d}t + g(X_t)\;\mathrm{d}W_t. dXt​=f(Xt​)dt+g(Xt​)dWt​.

    Mas o caso não autônomo pode ser tratado de forma análoga. Vamos considerar, ainda, uma condição inicial

    Xt∣t=0=X0. \left. X_t \right|_{t = 0} = X_0. Xt​∣t=0​=X0​.

    Expansão de Taylor estocástica

    A equação diferencial estocástica é interpretada como significando

    Xt=X0+∫0tf(Xs) ds+∫0tg(Xs) dWs. X_t = X_0 + \int_0^t f(X_s)\;\mathrm{d}s + \int_0^t g(X_s)\;\mathrm{d}W_s. Xt​=X0​+∫0t​f(Xs​)ds+∫0t​g(Xs​)dWs​.
